# VirtualDisplay

A macOS menu-bar app that pushes or shares a window to a headless virtual display and serves it over VNC.

Downloads are on the [Releases](https://github.com/fredp46/virtualdisplay-releases/releases) page. Builds are signed with Developer ID and notarized by Apple.

## Install

```sh
brew install --cask fredp46/tap/virtualdisplay
```

Or download the latest zip from Releases, unzip it and move VirtualDisplay.app to Applications.

On first launch, grant **Accessibility** and **Screen Recording** in System Settings → Privacy & Security, then relaunch.

Requires macOS 14 Sonoma or later.
