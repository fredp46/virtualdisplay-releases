For macOS 14 Sonoma and later

VirtualDisplay

A menu-bar app that gives your Mac an extra, invisible screen. Push any window onto it, then watch and control that window over VNC, in a browser, or from an AI agent, without it cluttering your own desktop.

Install Download for Mac

What it does

Push a window

Press ⌃⌥⌘V and the front window moves to the virtual display and fills it. ⌃⌥⌘R brings it back to where it was.

Share a window

Press ⌃⌥⌘S to stream just one window while it stays on your desktop, marked with a purple outline so you know what viewers see.

Virtual Desktop Window

Press ⌃⌥⌘D to see the virtual display live in a window. Share it whole in Teams, Zoom or Meet as a clean, separate desktop.

VNC and web viewer

A built-in VNC server on port 5901 and a browser viewer at 127.0.0.1:5902. Remote clicks and keys go to the app without moving your cursor.

MCP server for AI agents

Agents such as Claude Code can take screenshots, read the accessibility tree, click, type and pick menu items in the pushed window.

Encrypted remote access

A WireGuard peer is built in, with an optional SSH server and web terminal. Reach your Mac from your other devices with no VPN profile or admin password.

Install

With Homebrew (recommended)

brew install --cask fredp46/tap/virtualdisplay

Update later with brew upgrade --cask virtualdisplay.

Or download it

  1. Download the latest VirtualDisplay-<version>.zip from the releases page.
  2. Unzip it and drag VirtualDisplay.app into your Applications folder.
  3. Open it. Builds are signed and notarized by Apple, so it opens like any other app.

First launch

  1. VirtualDisplay lives in the menu bar; it has no Dock icon.
  2. Grant Accessibility (to move windows and send input) and Screen Recording (to capture the display) in System Settings → Privacy & Security.
  3. Quit and reopen VirtualDisplay so the permissions take effect.
  4. Optionally, turn on Launch at Login from the menu.

Get started

  1. Click a window and press ⌃⌥⌘V to push it to the virtual display.
  2. Connect a VNC client to vnc://127.0.0.1:5901 (default password password; change it from the menu), or open Web Viewer from the menu.
  3. To let an AI agent drive the window, add the MCP server to Claude Code: 
    claude mcp add --transport http virtualdisplay http://127.0.0.1:5902/mcp
  4. To reach it from another device, choose Remote Access → Add Device… and scan the QR code with the WireGuard app.

Good to know

  • Everything listens on 127.0.0.1 only. Other devices connect through the encrypted WireGuard tunnel.
  • VirtualDisplay uses Apple's private CGVirtualDisplay API, like DeskPad and BetterDisplay, so a future macOS release may break it, and it can't be sold through the App Store.
  • Quitting VirtualDisplay always returns the pushed window to your screen first.
